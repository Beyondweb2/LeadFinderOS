- **Question wording (Paul, 2026-11-20):** a NEW UK question never carries "UK" — every ask runs from `countryCode` gb (ChatGPT, Gemini, Google AI). Risky towns are written the local way from ONE table (`seedGuard.ts` `UK_LOCAL_PLACE_NAMES`); never guess a town that is ambiguous inside the UK. Frozen / locked / replayed questions keep their stored words. A UK answer that reads as abroad shows an amber note (`abroadAnswer.ts`, display only). Record: `docs/natural-question-wording.md`. Test: `scripts/natural-uk-questions.test.ts`.
- ⛔ We never publish content written in a business's name: yoursites.uk `/r/` retired (410); never delete `business_reports` rows. Every report renders live from `render-audit-report` (short code `findable.live/r/<code>`, UUID and legacy slug resolve forever); weekly-check and market audits are refused; client-facing copy is scanned by `client-copy-claims.test.ts`; operator copy contains competitors — never send it. Quick report = chat view (`renderQuickCheckReport`). Winnable / Not winnable = the v4 evidence rules in `docs/AUDIT_RULES.md` (`auditVerdict.ts` `decideVerdictV3` with locked spots, one firm per spelling `makeFirmMatchKey`, strict name match `strictName.ts`): each AI judged on its own 3 asks, an unread answer is "Couldn't measure" (never "AI named nobody"), too many = "Audit incomplete" (no figures) + one alert to Paul; registers are never firms. Audits before v3 keep the rule they were made on so a sent link never changes — re-score to a NEW link with `scripts/audit-rescore-v3.ts`.
